# Keptilon Prototype

Rebrand prototype for **Keptilon Universe** — Life Arc House + Operators & Guides.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4
- Framer Motion

## Scripts

```bash
npm install
npm run dev
npm run build
npm start
```

## Routes

| Path | Page |
|------|------|
| `/` | Home + Arc |
| `/how-we-work` | Operators & Guides |
| `/about` | About the house |
| `/contact` | Contact / routing form |
| `/cofwaf` | Restaurant consulting |
| `/destiny` | Astrology & wellness |
| `/academy` | Executive education |
| `/talentx` | Talent assessment |
| `/venture` | Capital & company building |
| `/privacy` | Privacy Policy |
| `/terms` | Terms & Conditions |

## Design system

- **A Parchment** (default): warm `#F3EEE6`, forest green, terracotta
- **C Night** (toggle in header): deep ink companion theme
